# ZITRAKSMODE-ADAPTIVE

## Прогресс переноса

Перенос исходного проекта Minecraft Forge 1.19.2 с Google Диска идёт по частям. Это **ещё не полная резервная копия** — сохраняйте оригинал на Диске.

| Этап | Состояние |
| --- | --- |
| Конфигурация проекта | Перенесены Gradle, wrapper, настройки Forge и история разработки |
| Java-исходники | В репозитории 511 файлов `.java`, включая классы предметов, событий, сети, сущностей и клиентского интерфейса; два файла исходно пустые |
| Ресурсы | Перенесены `mods.toml`, `pack.mcmeta`, mixins JSON и одна модель Blockbench; большая часть ресурсов ещё отсутствует |
| Рецепты и другие данные | На Диске обнаружены 73 JSON-рецепта, их ещё предстоит перенести; также остаются другие папки ресурсов |
| Сборка и запуск | Не проверены; работоспособность пока не подтверждена |
| Адаптация к другим версиям Minecraft | Ещё не выполнена |

Это нижняя граница, а не полный остаток: вложенные папки звуков, текстуры, 31 подпапка достижений и другие части проекта ещё не пересчитаны. Сравнение выполнено по путям, а не по содержимому. Процент готовности всего проекта пока не определить. Большой архив проекта и готовый JAR не перенесены из-за ограничения скачивания отдельных файлов в 100 МБ.

**Внимание:** исходный `build.gradle` отключает проверку сертификатов ForgeGradle; учитывайте это перед запуском сборки.
