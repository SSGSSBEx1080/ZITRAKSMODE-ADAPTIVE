# ZITRAKSMODE-ADAPTIVE

## Прогресс переноса

Перенос исходного проекта Minecraft Forge 1.19.2 с Google Диска идёт по частям. Это **ещё не полная резервная копия** — сохраняйте оригинал на Диске.

| Этап | Состояние |
| --- | --- |
| Конфигурация проекта | Перенесены Gradle, wrapper, настройки Forge и история разработки |
| Java-исходники | В репозитории 511 файлов `.java`, включая классы предметов, событий, сети, сущностей и клиентского интерфейса; два файла исходно пустые |
| Ресурсы | Перенесены базовые метаданные, геометрия, анимации, локализация, модели предметов, блоков и брони, blockstates и часть звуков; большая часть ресурсов ещё отсутствует |
| Рецепты и другие данные | Перенесены 73 JSON-рецепта, таблицы добычи блоков, теги предметов, структуры, 37 достижений из двух подпапок и часть данных генерации; другие папки ещё остаются |
| Сборка и запуск | Не проверены; работоспособность пока не подтверждена |
| Адаптация к другим версиям Minecraft | Ещё не выполнена |

### Оставшиеся ресурсы

Перенесены все обнаруженные в папках моделей 112 моделей предметов, 133 модели блоков и одна модель брони. Сравнение выполнено по путям, а не по содержимому. Перенесены три просмотренные вложенные папки звуков, две текстуры брони и достижения из папок `00_guest` и `01_numbers`. Остальные текстуры, 29 других подпапок достижений и другие части проекта ещё не пересчитаны и не перенесены полностью. Процент готовности всего проекта пока не определить. Большой архив проекта и готовый JAR не перенесены из-за ограничения скачивания отдельных файлов в 100 МБ.

**Внимание:** исходный `build.gradle` отключает проверку сертификатов ForgeGradle; учитывайте это перед запуском сборки.
