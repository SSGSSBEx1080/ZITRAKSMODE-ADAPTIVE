all versoins vibecode

## Импорт исходного проекта

Импорт с Google Диска выполняется по частям. Сейчас добавлены настройки Forge 1.19.2, Gradle Wrapper, история разработки, основные классы и несколько файлов ресурсов. Большая часть исходников и ресурсов пока отсутствует; сборка и запуск на этом этапе не проверялись и не ожидается, что они работают. Это не полная резервная копия проекта.

Исходный `build.gradle` отключает проверку сертификатов ForgeGradle; учитывайте это перед запуском сборки.
